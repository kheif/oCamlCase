Tuples

A tuple bundles a fixed number of values, possibly of different types, into one value. It is the simplest way to shape data, and the first step toward modeling with types.

Constructing tuples

A tuple is written with commas. Parentheses are conventional but it is the commas that build the tuple.

The type of a tuple uses * between the component types: (3, "three") has type int * string. The order matters and so does the length: int * string, string * int, and int * string * bool are three unrelated types.

tuples.ml 
let p = (3, "three")        (* int * string *)
let q = (1, 2.5, true)     (* int * float * bool *)
let origin = (0.0, 0.0)     (* float * float *)

Taking tuples apart: patterns

You rarely access tuple components with functions. Instead you destructure with a pattern that mirrors the construction.

destructure.ml 
let (x, y) = origin           (* x = 0.0, y = 0.0 *)

let dist (x1, y1) (x2, y2) =
  Float.sqrt ((x2 -. x1) ** 2. +. (y2 -. y1) ** 2.)

let swap (a, b) = (b, a)      (* 'a * 'b -> 'b * 'a *)

For pairs only, the standard library offers fst and snd, but a pattern is clearer in almost every case and works for any tuple size.

Key insight

Construction and destructuring are mirror images: (x, y) builds a pair on the right of = and takes one apart on the left. This symmetry between making data and matching data runs through the whole language, and pattern matching generalizes it from tuples to every data shape.

Tuples are not lists

  • A tuple has a fixed length known in the type, and components may have different types: int * string.
  • A list has any length, and every element has the same type: int list.

Use a tuple when the positions mean something (a coordinate, a key-value pair); use a list when you have many of the same thing.

One argument that looks like several

A function can take one tuple instead of several curried arguments. The types tell the two styles apart.

styles.ml 
let add_c x y = x + y      (* int -> int -> int    : curried *)
let add_t (x, y) = x + y   (* int * int -> int     : tupled  *)

The curried style supports partial application (see Currying) and is the OCaml default. The tupled style appears when the pair is itself a meaningful value, like a coordinate passed around as a unit. Constructors carrying several values, such as Triangle of float * float * float, take exactly one tuple argument; that is where tuples and variants meet (see Variants and Constructors).

When tuples stop scaling

By the time a tuple has three or four components, position alone no longer documents meaning: was the third float the price or the weight? At that point you want named fields, which is exactly what Records provide. A good rule: pairs almost always, triples sometimes, anything longer wants a record.
