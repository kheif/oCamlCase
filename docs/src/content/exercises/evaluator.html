Expression Evaluator

Define an arithmetic expression type as a variant and build an evaluator, a pretty-printer, and a simplifier. This exercise ties together variant types, pattern matching, and structural recursion on a tree-shaped data type.

The challenge
Build an expression evaluator
Hard

Support evaluation, pretty-printing, simplification, and tree inspection over a recursive variant type representing arithmetic expressions.

  • 01Define a variant type expr with constructors: Num of int, Add of expr * expr, Mul of expr * expr, Neg of expr.
  • 02Write eval : expr -> int that recursively evaluates an expression.
  • 03Write to_string : expr -> string that converts an expression to a fully parenthesized string, e.g. "(1 + (2 * 3))".
  • 04Write count_nodes : expr -> int that counts the total number of nodes in the expression tree.
  • 05Write simplify : expr -> expr that applies algebraic simplifications: Add(e, Num 0) and Add(Num 0, e) → e, Mul(e, Num 1) and Mul(Num 1, e) → e, Mul(_, Num 0) and Mul(Num 0, _) → Num 0, Neg(Neg e) → e.
  • 06Write contains_zero : expr -> bool that checks whether any Num 0 appears in the tree.

Hints

For eval, pattern match on each constructor. Add evaluates both sides and adds; Neg negates the recursive result.

For to_string, use Printf.sprintf to build parenthesized strings. string_of_int converts integers.

For simplify, the key insight: simplify recursively FIRST, then check for algebraic identities. The or-pattern | Add(e, Num 0) | Add(Num 0, e) matches both orderings.

Key insight

The expr type is a tree. Each constructor is a node: Num is a leaf, Add and Mul have two children, Neg has one. Every function on expr is structural recursion over this tree.

evaluator_solution.ml 
type expr =
  | Num of int
  | Add of expr * expr
  | Mul of expr * expr
  | Neg of expr

let rec eval = function
  | Num n -> n
  | Add (l, r) -> eval l + eval r
  | Mul (l, r) -> eval l * eval r
  | Neg e -> -(eval e)

let rec to_string = function
  | Num n -> string_of_int n
  | Add (l, r) ->
    Printf.sprintf "(%s + %s)" (to_string l) (to_string r)
  | Mul (l, r) ->
    Printf.sprintf "(%s * %s)" (to_string l) (to_string r)
  | Neg e ->
    Printf.sprintf "(-%s)" (to_string e)

let rec count_nodes = function
  | Num _ -> 1
  | Add (l, r) -> 1 + count_nodes l + count_nodes r
  | Mul (l, r) -> 1 + count_nodes l + count_nodes r
  | Neg e -> 1 + count_nodes e

let rec simplify = function
  | Add (e, Num 0) | Add (Num 0, e) -> simplify e
  | Mul (e, Num 1) | Mul (Num 1, e) -> simplify e
  | Mul (_, Num 0) | Mul (Num 0, _) -> Num 0
  | Neg (Neg e) -> simplify e
  | Add (l, r) -> Add (simplify l, simplify r)
  | Mul (l, r) -> Mul (simplify l, simplify r)
  | Neg e -> Neg (simplify e)
  | e -> e

let rec contains_zero = function
  | Num 0 -> true
  | Num _ -> false
  | Add (l, r) -> contains_zero l || contains_zero r
  | Mul (l, r) -> contains_zero l || contains_zero r
  | Neg e -> contains_zero e

let () =
  let e = Add (Mul (Num 2, Num 3), Neg (Num 4)) in
  Printf.printf "expr: %s\n" (to_string e);
  Printf.printf "eval: %d\n" (eval e);
  Printf.printf "nodes: %d\n" (count_nodes e);
  let e2 = Add (Mul (Num 5, Num 1), Num 0) in
  Printf.printf "before: %s\n" (to_string e2);
  Printf.printf "after:  %s\n" (to_string (simplify e2))

Walkthrough

eval. The simplest structural recursion. Each node computes its value from its children's values.

to_string. Demonstrates that different representations of the same data can be derived from the same recursive structure. Printf.sprintf builds fully parenthesized strings at each level.

simplify. Combines pattern matching with recursive descent. It must simplify children before checking for identities, or nested simplifiable expressions will be missed. The or-patterns handle commutativity of identity elements.

contains_zero. Shows that boolean predicates over trees use || to combine recursive results. The Num 0 pattern matches before the wildcard Num _ because OCaml checks patterns top to bottom.

Going further

Once the basic evaluator works:

  • Add a Div of expr * expr constructor and handle division by zero with the result type.
  • Write depth : expr -> int to compute the depth of the expression tree.
  • Write substitute : string -> expr -> expr -> expr by adding a Var of string constructor for symbolic expressions.
