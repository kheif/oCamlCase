Merge Sort

Implement merge sort from scratch in OCaml. Build three core functions step by step: split a list in half, merge two sorted lists, and the recursive sort. Make it polymorphic by accepting a comparison function.

The challenge
Build a polymorphic merge sort
Medium

Implement merge sort by composing three functions: split, merge, and sort. By parameterising over a comparison function, one implementation handles ascending order, descending order, and sort-by-any-criterion.

  • 01Write split : 'a list -> 'a list * 'a list that divides a list into two roughly equal halves by alternating elements.
  • 02Write merge : ('a -> 'a -> int) -> 'a list -> 'a list -> 'a list that merges two sorted lists into one sorted list using a comparison function.
  • 03Write msort : ('a -> 'a -> int) -> 'a list -> 'a list that recursively splits, sorts, and merges.
  • 04Test msort compare on an integer list (compare is OCaml's built-in polymorphic comparison).
  • 05Write sort_descending using msort with a reversed comparator: fun a b -> compare b a.
  • 06Write sort_by_length : string list -> string list that sorts strings by their length using msort with a custom comparator.
  • 07Write is_sorted : ('a -> 'a -> int) -> 'a list -> bool that checks whether a list is sorted according to a comparison function.

Hints

For split, the recursive call returns a pair. Destructure it with let (l, r) = split rest in then cons x onto l and y onto r.

For merge, compare with cmp x y <= 0. If x comes first, cons it and recurse on xs and l2. Otherwise cons y and recurse on l1 and ys.

For msort, the base case is lists of length 0 or 1 (already sorted). The or-pattern ([] | [_]) matches both.

Key insight

msort is polymorphic because it never looks at element values. It delegates all comparisons to cmp. By swapping the comparator you get ascending sort, descending sort, or sort-by-any-criterion for free.

mergesort_solution.ml 
let rec split = function
  | [] -> ([], [])
  | [x] -> ([x], [])
  | x :: y :: rest ->
    let (l, r) = split rest in
    (x :: l, y :: r)

let rec merge cmp l1 l2 =
  match l1, l2 with
  | [], _ -> l2
  | _, [] -> l1
  | x :: xs, y :: ys ->
    if cmp x y <= 0 then x :: merge cmp xs l2
    else y :: merge cmp l1 ys

let rec msort cmp = function
  | ([] | [_]) as lst -> lst
  | lst ->
    let (l, r) = split lst in
    merge cmp (msort cmp l) (msort cmp r)

let sort_descending lst =
  msort (fun a b -> compare b a) lst

let sort_by_length lst =
  msort (fun a b -> compare (String.length a) (String.length b)) lst

let rec is_sorted cmp = function
  | [] | [_] -> true
  | x :: (y :: _ as rest) ->
    cmp x y <= 0 && is_sorted cmp rest

let () =
  let nums = [5; 2; 8; 1; 9; 3] in
  let sorted = msort compare nums in
  Printf.printf "sorted: [%s]\n"
    (String.concat "; " (List.map string_of_int sorted));
  let desc = sort_descending nums in
  Printf.printf "desc:   [%s]\n"
    (String.concat "; " (List.map string_of_int desc));
  let words = ["cat"; "elephant"; "ox"; "bear"] in
  let by_len = sort_by_length words in
  Printf.printf "by len: [%s]\n"
    (String.concat "; " by_len);
  Printf.printf "is_sorted: %b\n" (is_sorted compare sorted)

Walkthrough

split. Alternates elements between two accumulating lists. This ensures roughly equal halves regardless of input order.

merge. The heart of merge sort. The comparison function cmp returns a negative number, zero, or positive number, the same convention as OCaml's built-in compare.

msort. Divide-and-conquer: split the problem in half, solve each half, combine the solutions. The recursion bottoms out at length 0 or 1.

sort_descending. Demonstrates the power of higher-order functions: one line changes the sort order by flipping the comparator arguments.

is_sorted. Uses an as pattern: y :: _ as rest binds both y (the head) and rest (the full tail starting at y), avoiding redundant destructuring.
