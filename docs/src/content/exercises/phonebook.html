Phonebook

Model a phonebook as a (string * string) list of name-number pairs. Practice list operations, closures for filtering predicates, and higher-order functions.

The challenge
Build a phonebook with lookup, search, and formatting
Easy

A phonebook is a list of (name, number) pairs. Build a library of functions that add, find, remove, search, and format entries using list operations, closures, and higher-order functions.

  • 01Define a type alias type entry = string * string and create a sample phonebook list with at least 4 entries.
  • 02Write add name number phonebook that prepends a new entry.
  • 03Write find_number name phonebook that returns string option, the phone number for a given name or None.
  • 04Write remove name phonebook using List.filter to remove all entries with that name.
  • 05Write search prefix phonebook that returns all entries whose name starts with prefix (hint: use String.sub and String.length).
  • 06Write names phonebook using List.map to extract just the names.
  • 07Write count phonebook to return the number of entries.
  • 08Write format_entry that returns "name: number" and format_all that formats every entry using List.map.

Hints

For find_number, List.find_opt returns Some element or None. Match on the result to extract just the number from the pair.

For search, compare a substring: String.sub name 0 (String.length prefix) = prefix. Guard against short names with a length check first, otherwise String.sub will raise an exception.

Notice the pattern

Every filtering function follows the same shape: List.filter (fun (n, _) -> <condition>) pb. The closure captures the parameter (name, prefix) from the enclosing scope.

phonebook_solution.ml 
type entry = string * string

let phonebook = [
  ("Alice", "555-1234");
  ("Bob", "555-5678");
  ("Charlie", "555-9012");
  ("Diana", "555-3456")
]

let add name number pb = (name, number) :: pb

let find_number name pb =
  match List.find_opt (fun (n, _) -> n = name) pb with
  | Some (_, num) -> Some num
  | None -> None

let remove name pb =
  List.filter (fun (n, _) -> n <> name) pb

let search prefix pb =
  let len = String.length prefix in
  List.filter (fun (n, _) ->
    String.length n >= len &&
    String.sub n 0 len = prefix
  ) pb

let names pb = List.map (fun (n, _) -> n) pb

let count pb = List.length pb

let format_entry (name, number) =
  Printf.sprintf "%s: %s" name number

let format_all pb =
  List.map format_entry pb

let () =
  Printf.printf "Find Alice: %s\n"
    (match find_number "Alice" phonebook with
     | Some n -> n | None -> "not found");
  Printf.printf "Names: %s\n"
    (String.concat ", " (names phonebook));
  let pb2 = add "Eve" "555-7890" phonebook in
  Printf.printf "After add: %d entries\n" (count pb2);
  let matches = search "Ch" phonebook in
  List.iter (fun e -> print_endline (format_entry e)) matches

Walkthrough

add. Uses cons ::. Prepending is O(1) and produces a new list without mutating the original.

find_number. Uses List.find_opt which returns an option, avoiding exceptions. The match extracts just the number from the found pair.

remove and search. Both use List.filter with closures that capture the function parameter. remove keeps entries where the name does not match; search keeps entries where the name starts with the prefix.

format_entry. Uses Printf.sprintf for type-safe string formatting. format_all maps it over every entry, demonstrating that named functions can be passed directly to higher-order functions without wrapping in a lambda.
